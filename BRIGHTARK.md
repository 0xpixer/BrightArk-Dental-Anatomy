# BrightArk presentation fork

This deployment adapts the visual presentation of [Dental Scope](https://github.com/Yoosseph/dental-scope) for the BrightArk Order Portal. The anatomy data, educational content, model behavior, original credits, and source links remain attributed to the upstream project.

- Application code: MIT License (see `LICENSE`)

- Educational content and additional anatomy sources: see `CREDITS.md`

BrightArk-specific changes are limited to branding, typography, colors, embedding, and deployment configuration.
